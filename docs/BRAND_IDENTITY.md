# Konkourix Brand Identity

**Status:** APPROVED BRAND DIRECTION
**Product Owner decision:** 2026-09-30

## Brand Name

The brand is **konkourX / کنکوریکس**. The uppercase **X** is the distinctive Latin brand element and must remain visibly intentional.

## Character

Konkourix is a modern educational SaaS brand: professional, optimistic, student-friendly, premium, and approachable.

The brand must not become:

- sci-fi;
- gaming-neon;
- childish;
- visually noisy or excessively decorative.

## Core Colors

- Primary Blue: `#2563EB`
- Violet: `#8B5CF6`
- Cyan: `#06B6D4`
- Deep Navy: `#0F172A`

## X System

The X uses one geometry in two expressions:

- a glossy or glass brand version for large, high-value brand moments;
- a simplified flat version for favicons, sidebars, and other small UI contexts.

The small version simplifies rendering, not identity or geometry.

## Visual Direction

- Glassmorphism is restrained and must preserve clarity and contrast.
- Dark mode is mostly matte and solid.
- Glow is limited to selected, high-value brand moments.
- Student-facing expression is calmer and more motivational.
- Counselor-facing expression is denser, more operational, and less decorative.
- A 3D student illustration may appear in marketing, login, onboarding, or selected banners. It must not be repeated throughout data-heavy workflows.

## Language and Typography

Persian-first RTL is the default product direction. English typography uses Inter.

IRANSansX may be used only when owner-supplied licensed font files already exist. Do not download, embed, redistribute, or simulate licensed font binaries. Without those files, use Vazirmatn or an appropriate system fallback.

## State Classification

### CURRENT IMPLEMENTED STATE

The applications have existing light/dark foundations and independent Student and Counselor shells. Existing UI does not yet constitute full implementation of this brand direction.

### APPROVED FUTURE STATE

The name, character, colors, X system, RTL direction, role-specific expression, dark-mode restraint, illustration boundaries, and typography licensing rule above are approved.

### EXPLORATORY / DEFERRED

Final logo artwork, downloadable assets, icon construction, motion behavior, typography files, and a detailed brand manual require separate approval. This document does not authorize application-source changes.
