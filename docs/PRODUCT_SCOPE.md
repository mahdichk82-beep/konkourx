## Superseded Scope Notes

The 2026-10-01 Product Master Blueprint established that KonkourX is a comprehensive Persian EdTech platform rather than only its currently implemented Student/Counselor planning core. That consolidation has now been replaced by the clearer 0–6 canonical structure in `PRODUCT_MAP.md`.

The following decisions are no longer unresolved:

- Question ↔ Curriculum cardinality is many-to-many, with an optional Primary Curriculum Link for display/grouping.
- Current Classroom direction is provider-abstracted external meeting links; internal Classroom/WebRTC remains future.
- School/Institute is an organizational layer over shared platform engines.
- Product, Plan, Entitlement, Subscription, and Payment are separate concepts.
- Payments are provider-abstracted and include a manual Card-to-Card review path.

This legacy file provides no implementation authorization.
